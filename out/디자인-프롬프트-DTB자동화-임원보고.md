### 7. 【필수】 후보 선별 → LLM 30건 → 20건
3단 흐름. 각 단에 '무엇을 기준으로'를 명시.

**① 500건 전수 판정 (고 / 중 / 저)**
- tier0 뉴스는 **한 건도 건너뛰지 않고** 검토.
- 판정 축 4개: **A 주체 × B 주제 × C 사건 단계 × D 핵심 어젠다**
  - A 주체: 경쟁사 > 빅테크 > 소버린AI 주체 > 대기업 > 학계 > 지자체
  - B 주제: 국책과제·특파모·AX수주는 전부 '고' / 네트워크·보험은 전부 '저'
  - C 단계: **완료(계약·선정·출시) > 진행(추진·검토) > 분석**
  - D 어젠다: 배제 7항목(반도체 소자연구·양자·보험·증권상품·통신망·이미지센서·DC 기자재)에 해당할 때만 제외

**② 30건 선정 — 텔레그램 초안 채널 발송**
- '고' 전량 → 모자라면 '중'에서 중요도 순
- 카테고리는 **배치 기준일 뿐 정원이 아님**. 없는 카테고리는 섹션째 제외
- 최근 5회 발송분과 대조해 중복 제거 (기계는 URL 동일만 자르고, 제목이 유사한 경우 LLM이 판단)

**③ 20건 재선별 — 임원 보고용**
- 판단 축 3개: **파급**(산업 구조를 바꾸는가) / **확정성**(일어난 일인가 예정인가) / **SKT AI 연관성**(AIDC·AI Model·독파모/모두의AI/특파모·에이전트·피지컬AI·국내 AX 발주)

|---|---|---|---|
| `수집` | 사람이 실은 기사가 후보 목록에 아예 없음 | 링크를 못 찾은 기사를 파이프라인이 통째로 버리고 있었음. **사람 브리프 기사의 29%가 이 사유로 소실** | 링크 미확보 후보 150건을 프롬프트에 되살리는 단계 신설. 상위권(27·54·70위) 기사가 복구됨 |
| `수집` | 큐레이션 채널 기사가 조용히 누락 | 슬랙 파서가 **제목에 대괄호가 들어간 기사**를 인식 못 함 | 파싱 규칙 수정. 14일 164건 중 **11건 유실**을 해소 |
| `채점` | 사람이 꾸준히 싣는 기사가 낮은 점수로 탈락 | 채점이 **제목만** 보고 있었음. 후보의 **96.9%에 본문 요약이 없는 상태**로 점수가 매겨짐 | 본문 재채점 단계 신설(링크 해결 후 · 선별 전). 제목만으로 안 보이던 사건 회수 |
| `채점` | 큰 금액의 투자·M&A 기사가 묻힘 | `3500억 받은` 같은 **통화어가 생략된 한글 금액**을 금액으로 못 읽음 | 금액 인식 확장 + 비금액(파라미터·토큰) 오탐 가드. 해당 기사 **5점 → 10점** |
| `선별` | 후보 하위 구간의 기사를 반복해서 놓침 | 위에서부터 담다가 **30건이 차면 멈춰**, 하위 구간을 판정조차 하지 않았음 | 절차를 **전수 판정 → 순위 → 컷** 순으로 고정. 그 구간에 있던 정답지 4건(놓친 7건의 절반)이 대상이 됨 |
| `측정` | 채점 결과 자체를 신뢰할 수 없었음 | 정답지 파서가 사람이 손편집한 **제목 형식 변형을 못 읽음**. 실측 14건 중 8건만 파싱 | 제목 형식 4종을 모두 수용. 채점이 **틀린 값 위에서 돌던 문제** 해소 |

우측 또는 하단에 작은 요약 카드 2개:
- **`57%`** 정답지 기사 중 Tier 0가 잡아낸 비중 — 후보로는 22%뿐인 통로가 절반 이상을 담당. 큐레이션 소스 보존이 최우선 과제였던 근거
- **`절반`** 개선 항목 중 '수집·측정 결함'이 차지한 비중 — 선별 알고리즘보다 **파이프라인 결함이 먼저**였다

하단 메시지: "규칙을 늘리는 것이 아니라 **적용 순서와 측정의 정확도**를 고치는 작업이 대부분이었다"

### 11. 【필수】 현재 상황과 향후 계획
좌측 '현재', 우측 '계획' 2단.

**현재 (2026.08 기준)**
- 수집–선별–작성–발송 **전 과정 무인 실행**. 사람은 최종 검토만
- **소스 수집 완료** — 수집율 100%에 근접, 더 넓힐 소스가 남아 있지 않음
- 텔레그램 **초안 채널**로 자동 발송, 운영 채널은 사람 확인 후 발송
- 매일 자기 채점 + 검증 엑셀 자동 생성
- 일치율 **60% 중반**에서 진폭 있게 유지

'현재' 4줄 중 **수집 완료**와 **일치율 60% 중반**을 시각적으로 대비시킬 것.
(수집은 끝났고 남은 과제는 선별 품질이라는 메시지가 한눈에 보이게)

**계획** — 9월 3주 완료 목표. 주차별 로드맵을 **가로 타임라인**으로 그릴 것.

| 시점 | 과제 | 기대 효과 |
|---|---|---|
| **9월 1주** | **선별 로직 고도화** | 일치율 **80%대 안착** |
| **9월 2주** | **최종 뉴스 후보 20건 → 15건 압축** | 사람 발송 기준(하루 평균 15건)에 정렬 |
| **9월 3주** | **운영 완전 자동화** (사람 최종 검토 단계 제외) | 무인 운영 전환 |

타임라인 아래에 마일스톤 캡션 3개를 짧게:
`품질` → `압축` → `무인화` 순서로 진행된다는 것이 보이게 배치.
