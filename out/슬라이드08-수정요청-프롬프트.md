마지막 장 **「08 향후 계획」** 을 아래대로 수정해 주세요. 레이아웃(좌측 현재 / 우측 타임라인 2단)과 색·타이포는 그대로 두고 내용만 바꿉니다.

## 1. 제목 교체

기존 제목 「수집은 완료, 남은 과제는 선별 품질」을 아래로 바꿔 주세요.

> **수집 완성, 이제 규칙 고도화와 무인 운영으로**

'남은 과제'처럼 미완·부정 뉘앙스의 표현은 쓰지 마세요. 아래 대안 중 하나를 써도 됩니다.

- 수집에서 발송까지, 9월 3주 완전 자동화
- 소스 수집 완성 → 선별 규칙 고도화 → 무인 운영

## 2. 좌측 '현재' 블록 — 일치율 수치 삭제

**`67.6%` 와 「일치율 — 진폭 있게 유지, 개선 필요」 박스를 통째로 삭제**해 주세요. 일치율은 반드시 올려야 하는 지표가 아니므로 이 장에서 강조하지 않습니다. **본문 어디에도 일치율 수치·목표치를 남기지 마세요.**

박스가 하나 빠지면서 생기는 자리는 아래처럼 처리해 주세요.

- `98.4%` 「뉴스 커버리지」 박스를 **좌측 폭 전체로 확장**하고 네이비 배경을 유지합니다.
- 그 아래 캡션을 한 줄 답니다 — **"더 넓힐 소스가 남아 있지 않은 수준"**
- 붉은 강조선(기존 67.6% 박스 상단)은 함께 제거합니다. 이 장에서 레드는 우측 타임라인의 '9월 3주' 노드에만 씁니다.

기존 하단 3줄은 그대로 유지하되 순서만 아래로 정리해 주세요.

1. 수집–선별–작성–발송 전 과정 무인 실행
2. 초안을 텔레그램 채널로 자동 발송, 담당자 확인 후 최종 발송
3. 매일 자기 채점 + 검증 엑셀 자동 생성

## 3. 우측 '계획' 타임라인 — 2개 노드 내용 교체

헤더는 「계획 — 9월 3주 완료 목표」 유지. 노드 2개의 문구만 바꿉니다.

**9월 2주 노드**

- 제목: **채점·선별 규칙 고도화**
- 설명: 매일 검증 결과를 반영해 채점 기준과 선별 규칙을 정교화
- 하단 마일스톤 라벨: **고도화**
- ※ 기존의 "일치율 80%대 안착" 문구는 **삭제**합니다.

**9월 3주 노드** (레드 강조 유지)

- 제목: **완전 자동화 운영**
- 설명: 사람 최종 검토 단계까지 제외, 수집부터 발송까지 무인 운영 전환
- 하단 마일스톤 라벨: **무인화**

## 4. 톤

이 장은 '아직 부족한 것을 고치겠다'가 아니라 **'수집은 완성했고 이제 운영을 사람 손에서 떼어낸다'** 는 진행형 메시지입니다. 개선·미달·과제·부족 같은 단어를 쓰지 마세요.
