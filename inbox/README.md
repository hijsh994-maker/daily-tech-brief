# inbox — 외부 작업 결과 전달 지점

DTB 파이프라인이 **다른 스케줄 작업의 산출물을 받아 가는 폴더**입니다.

| 파일명 | 무엇 | 받는 명령 |
|---|---|---|
| `aibrief-YYYY-MM-DD.md` | 매일 08:00 'AI 뉴스 큐레이션' 작업 결과 | `bash cowork/run.sh aibrief` |

- 파일이 없으면 DTB 는 **조용히 건너뜁니다**(에러 아님).
- 서식은 자유입니다. 제목과 URL 이 한 항목 안에 있기만 하면
  마크다운 링크 목록 · DTB 발송본 서식 · `o 링크:` 서식 · `제목 — URL` 을 모두 인식합니다.
- **URL 이 없는 항목은 버려집니다.** 링크 없는 기사는 링크 해결 쿼터만 소모합니다.
