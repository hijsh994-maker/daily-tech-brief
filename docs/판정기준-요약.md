# 판정 기준 요약 (2026-11-09 정리 — 판정 직전에 이 한 장을 읽는다)

자세한 근거·실측은 매일 프롬프트의 `[편집자 평가 기준]`(brief.py 가 만든다)과 `docs/사례집.md` 에 있다.

## 1. 판정 순서 (편집자의 문장 순서)
'[주체]의 [분야] 기사로, [사건의 알맹이]이므로 중요도 [등급]'

   (6) 이미지센서 (7) AI DC 기자재 납품(발전기·변압기·전선·냉각 — 금액이 커도 저, F1 보다 우선. 빅테크의 발전기 '조달'도 같음, 사례 09-17)
   (8) 특파모 사업(09-04 사용자 지시 원문: 사이버보안 특화 AI 파운데이션 모델 사업의 선정·컨소시엄·개발 — 빅테크 보안 모델 출시는 배제 아님.
       정부 'AI 특화 파운데이션 모델 프로젝트'의 다른 분야(의과학 등)는 **배제 대상 아님** — 11-09 사용자 확정)
   (9) 특허·지식재산 제도 (10) 건설사 주체 AIDC 시공
2. **A 주체 × B 주제 × C 단계.** 완료(출시·인수·선정·구축·계약·실증)는 올리고, 진행(추진·검토·협상·논의)은 내리고,
   분석(시사점·원인·선언성 인터뷰)은 새 사실이 없으면 내린다. 예외: 선도기업 CEO 가 핵심 어젠다를 말하면 고.
3. **E 알맹이.** '큰 회사 + 큰 숫자'만으로 고가 아니다. 판단이 바뀌지 않으면 평이. 재집계·짜집기 기사는 고 아님.
4. **F 하드 규칙**
   - F1 1천억원 이상 = 큰 건(기자재·단순 GPU 물량은 제외 — 물량 확보는 금액이 커도 '중').
   - F9 SKT 가 주어면 한 칸 하향. F10 경쟁사(KT·네이버·카카오·LGU+·LG, 서열 없음) + 핵심 어젠다(신규 서비스·AI 전략·수주·파트너/인력/조직)는 고.
     단 '논의·검토' 단계 단독 보도는 F10 예외가 아니다.
   - 투자·자금조달은 '추진'이어도 새 숫자(규모·가치·주도 투자자)가 있으면 고. 숫자 없는 검토설·IPO 로드쇼는 아님.
   - 중국 빅테크 신규 모델·오픈소스는 F2 로 내리지 않는다. 해외 규제·수출통제는 한 단계 내린다. 국내 AI 규제 입법은 '추진'이어도 고.
   - 휴머노이드·로봇 파운데이션/월드모델은 한 단계 올린다. 산업용 자동화 로봇 실증·부품 납품은 '중' 이하. 글로벌 로봇 행사는 하루 1건만 고.
   - 빅테크 요금제·구독 출시와 GA(베타 종료)는 제품 출시. 빅테크 앱의 작은 기능 추가는 '중'.
   - SK 그룹사 AX 는 캡티브 영업 정보(올림). 최태원·유경상 발언은 AI 관련일 때 가점.
   - **실적 기사(분기 매출·영업이익·가이던스)는 '저'**(빅테크도 예외 없음).
5. **G 신규성 — '후보로 봤다' ≠ '독자가 안다'.** 깎는 근거는 실제 발송분(30일 발송본)·사용자 제외분(rejected.jsonl)뿐.
   - **이미 실은 사건의 공식 발표·재보도·완료·당사자 반응·재확인은 고가 아니다**(11-09 브룩필드·텍사스, 11-04 메타 회사채).
     같은 주체라도 앵글(투자 / 제품 실사용 / 전략·조직 / 규제·사고)이 다르면 다른 사건.
   - 과거 사실 재조명(본문 날짜가 창 밖)은 고 아님(11-04 챗GPT 옛 보안 우려, 11-09 셰브론-MS 6월 계약).
   - 최우선 어젠다(독파모·모두의 AI·소버린·AIDC)의 **새 논의(첫 보도)는 기본 고**(11-04 사용자 결정 R8).

## 2. 사유 형식
- **고:** `<올린 근거> / <내릴 뻔한 근거와 넘는 이유> 새사실:<본문에 실제로 있는 문장>` + 축 이름(F1·F10·독파모·반향…).
  [중복의심]이면 `중복검토:`, 기자재·물량·동일주체면 `기자재검토:`·`물량검토:`·`동일주체:`.
- **중:** 축 이름을 남긴다(E축 알맹이 / C축 진행 / F2 중국 / F7 언론사 분석 / 지표갱신 / 중복흐름 …). 신규성으로 내리면 `발송근거:<MM-DD 헤드라인>`.
- **저:** 닫힌 코드 `배제N-<항목>` / `운영공지` / `채용인력` / `사설칼럼`(지면 한정) / `시황실적` / `중복` / `AI무관` / `평이`.
