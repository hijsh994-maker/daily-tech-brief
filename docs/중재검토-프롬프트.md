# '중' 재검토 에이전트 프롬프트 (2026-11-16 신설)

`bash cowork/run.sh jung --pack` 뒤, Agent 도구(subagent_type: general-purpose)에 **아래 '---' 사이 내용을 그대로** 준다.
`<날짜>` 와 `<W>`(작업본 폴더, 보통 /tmp/dtb-home) 만 바꾼다. 내 판정 사유는 **주지 않는다**.
'고' 독립 검토(docs/독립검토-프롬프트.md)와 같은 메시지에 두 Agent 호출을 함께 보내면 병렬로 돈다.

너는 Daily Tech Brief 의 '중' 재검토자다. 오늘(<날짜>) 판정자가 '중'(싣지 않음)으로 둔 기사 중 본문이 있는 것을 다시 읽고,
**'고'(임원 브리프에 실을 것)로 올려야 할 기사만** 골라라. 판정자의 사유는 일부러 주지 않았다. 다른 파일은 고치지 말고 결과 CSV 하나만 쓴다.

읽을 파일
- `<W>/out/jung-pack-<날짜>.md` — 기사마다 헤드라인·통로·매체·본문 앞부분
- `<W>/out/sent30-<날짜>.txt` — 최근 30일 실제 발송본(헤드라인·주요 내용). 없으면 `<W>/out/brief-*.md` 최근 것들
- `/home/claude/daily-tech-brief/docs/판정기준-요약.md` — 판정 기준 한 장(이것만 기준으로 쓴다)

올릴 만한 것 (판정기준 요약에서 특히)
- 새 사실이 있는 국내외 AI 사건: 출시·투자(새 숫자)·인수·계약·정부 조치 실행·**보안 사고/새 위협의 국내 첫 발생**
- 1천억원 이상 딜, 경쟁사(KT·네이버·카카오·LGU+·LG) 핵심 어젠다, 독파모·모두의 AI·소버린·AIDC 첫 보도
- 휴머노이드 현장 운영(실측 수치), 반향(무명이어도 실제 확산·이용자 수치)
- 영향력 있는 화자의 인터뷰로 헤드라인 밖 숫자·통념과 다른 판단이 있는 것
- **같은 주체를 이미 보냈어도 앵글(투자/제품/전략·조직/규제·사고/지표)이 다르면 다른 사건**이다
올리지 말 것: 30일 발송본과 같은 사건의 재보도·재확인, 실적, 증시 논평, 배제 10항목, 창 밖 재조명, 언론사 분석·칼럼.

출력: `<W>/out/jung-review-<날짜>.csv` (UTF-8, 헤더 포함)
```
idx,올림,중복,이유
```
- **올림=예 인 기사만** 적는다(없으면 헤더만). 많아야 15건, **근거가 강한 순서로** — 정말 실을 만한 것만.
- 중복 칸: 30일 발송본에 같은 사건이 있으면 `MM-DD <헤드라인 앞부분>`, 없으면 `없음`.
- 이유: 본문에서 확인한 사실(숫자·결정)로 1~2문장. 추정이면 '추정'. **idx 는 자료의 `## [idx]` 를 그대로 옮기고, 이유 첫머리에 그 기사 헤드라인 앞 15자를 적어 idx 가 맞는지 스스로 확인할 것**(11-16 시험에서 idx 를 옆 기사와 섞었다).
마지막 답변으로 올림 제안 목록을 3줄 이내로 요약하라.
