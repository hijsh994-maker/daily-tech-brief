# 부록

## 부록 A. v2 가 Gmail 없이 돌아가는 이유 (한 장 요약)

```
[옛 방식 v1]
  지메일 ──(Gmail MCP)──> Claude ──> newsclips-mail ──> tier0
     ↑ 회사 계정에서 개인 지메일 커넥터가 막히면 여기서 끊김

[v2]
  지메일 ──(메일 전달)──> #dtb-tier0 채널 이메일 주소
                              ↓ 슬랙이 text/html 파일로 만듦
                    Claude ──(Slack MCP)──> slack_read_file
                              ↓ body-plain 만 꺼냄
                         newsclips-slack ──> (기존 지메일 파서) ──> tier0
```
- **파서는 하나**입니다. 지메일 본문과 `body-plain` 형식이 같아서
  `newsclips_mail.py` 를 그대로 씁니다.
- 슬랙 메시지 본문이 **비어 있는 것이 정상**입니다. 내용은 파일 안에 있습니다.

## 부록 B. 새 계정에서 처음 쓸 때 걸리는 권한

`slack_read_file` 은 v2 에서 처음 쓰는 도구입니다. **스케줄 실행 중에는
권한 승인 창을 띄울 수 없어 거기서 멈출 수 있습니다.**

→ STEP 12 리허설을 **반드시 수동으로 한 번** 돌리세요. 그때 승인해 두면
   이후 스케줄 실행에서 다시 묻지 않습니다.

## 부록 C. 이관 뒤에도 옛 폴더를 지우지 마세요

최소 2주는 둡니다. 새 계정에서 문제가 생기면 대조할 원본이 필요합니다.
2주 뒤 `truth-*.json` 과 `out/` 만 백업해 두고 정리하면 됩니다.
