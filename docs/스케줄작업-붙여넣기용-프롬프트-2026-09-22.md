## ★ 이 프롬프트가 직접 정하는 것

**발송 — 2026-09-22 사용자 지시로 자동 발송이다.**
사용자 원문: *"내일부터는 판정한 결과로 텔레그램 발송까지해!!! 내가 검토 없어"*
- 9단계에서 `send dry` → `verdict-xlsx` → `push` → **`bash cowork/run.sh send`** 까지 간다.
  **사용자 확인을 기다리지 않는다.**
- 발송 대상은 **초안 채널(TELEGRAM_DRAFT_CHAT_ID)**. `run.sh send final`(운영 채널)은
  **절대 쓰지 말 것.**
- 게이트(`cats`·`newfact`·`case`·`repeat`·`agenda`)는 **전부 돌리되 발송을 막지 않는다**
  (09-22 사용자 선택: '경고만 남기고 무조건 발송'). 대신 실패한 게이트 이름과 사유를
  **10단계 보고와 PushNotification 에 반드시 적는다.** 검토자가 없어 그 기록이 유일한
  사후 추적 수단이다.
- 검토자가 없다는 것은 판정을 대충 해도 된다는 뜻이 **아니다.** 7단계
  `hist`·`repeat`·`bodygo` 를 전보다 엄격히 적용한다. 09-22 실측으로 hist 가
  어제 이미 나간 기사 2건과 09-18 에 나간 1건을 '고'에서 걸러냈다. 이제 그런 건이
  걸러지지 않으면 그대로 발송된다.

**환경 제약 (어기면 즉시 깨지는 것들)**
- bash 호출 상한 약 178초. `tier2`/`links`/`body`/`linkcheck`/`bodygo` 는
  **timeout_ms 175000**, `collect` 는 120000, 나머지는 45000.
- **`links` 를 한 호출에 여러 번 넣지 말 것.** 한 호출에 한 번씩, '전부 시도 완료'까지 반복.
- **파이썬 스크립트를 python3 로 직접 부르지 말 것.** `run.sh` 를 거쳐야 secrets.env 의
  네이버 키·텔레그램 토큰이 실린다. 예외는 `refine.py --no-links` 뿐.
- 작업본(`/tmp/dtb-<세션>`)과 마운트는 다른 폴더다. **`run.sh push` 를 빠뜨리면 그날 작업이
  사라진다.** 파이프라인 코드를 고칠 일이 있으면 **마운트 쪽**을 고친다.
- `run.sh sync` 는 맨 처음 한 번만(작업본이 통째로 사라진 경우만 예외).

**오늘 날짜 산출물이 이미 있으면 재실행하지 말 것.**
`out/brief-<오늘>.md` 와 `out/prompt-<오늘>.txt` 가 이미 있으면 상태만 확인해 보고하고 멈춘다.
